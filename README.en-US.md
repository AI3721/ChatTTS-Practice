# ChatTTS-Practice
> [!TIP]
> A beginner practice project based on ChatTTS with FastAPI+Gradio, suitable for newcomers
## Running the Project
### 1. Start FastAPI
```bash
cd fastapi
uvicorn main:app --port 7788
```
### 2. Start Gradio
```bash
cd gradio
python demo.py
```
